# Архив устаревших миграций

Эти SQL-файлы находились в `supabase/migrations/`, но их номера версий отсутствуют в истории действующей базы FAM по состоянию на 09.11.2026. Часть файлов — старые или повторные черновики миграций, уже применённых под другими номерами.

Файлы сохранены здесь для истории, но намеренно вынесены из `supabase/migrations/`, чтобы Supabase CLI не пытался автоматически выполнить устаревший SQL. Не запускайте эти архивные сценарии на production-базе.
