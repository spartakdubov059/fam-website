# Сверка загрузки изображений доски — 23 ноября 2026

Источник: [`main` 241e3d3](https://github.com/spartakdubov059/fam-website/commit/241e3d302f4afcceb57a75a977053fa1125d8a9a). В FAM карточки теперь отображаются до завершения `hydrateListingImages`; после подписания URL карточки и избранное обновляются, параллельные запросы гидрации объединяются.

В RU эквивалентного этапа подписания URL нет. `ru-migration/app/web/public-board.js` получает school-scoped карточки через same-origin `/api/v1/listings`, задаёт фото только как `/api/v1/listings/:id/photo`, а изображение браузер загружает независимо с `loading="lazy"`. Карточки не ждут загрузки или декодирования изображения; фото проходит через защищённый backend маршрут. Изменение source перенесено по смыслу уже существующей схеме.

Отдельная оговорка: после ответа списка UI ожидает личные данные избранного и собственных объявлений, чтобы правильно показать соответствующие действия; для событий он также запрашивает собственные регистрации. Сбой этих вспомогательных запросов обрабатывается пустым/недоступным состоянием, но длительно зависший запрос способен задержать сборку всей доски. Это отдельный вопрос устойчивости, не изменение из source `241e3d3`.
