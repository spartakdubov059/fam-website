# Журнал изменений FAM

Все даты указаны по дате внесения изменения. Статус публикации указывается только после фактической проверки.

## 2026-11-08

### Документация и рабочий процесс
- Добавлен документ с ролями команды, границами ответственности и очередностью внедрения.
- Зафиксированы приоритетные пробелы модерации: локальный детектор контактов объявлен, но не вызывается; для объявлений и сообщений нет подтверждённой общей очереди ручной проверки.
- Добавлены ссылки на официальную документацию OpenAI по Moderation API, лимитам и хранению данных.
- Добавлен стартовый синтетический набор русскоязычных регрессионных примеров для проверки безопасных текстов, контактов и возможных ложных срабатываний.

Статус: изменения документации сохранены в GitHub. Публикация сайта не требуется; изменения не меняют поведение приложения.


### Модерация и приватность
- Подключён локальный детектор телефонов, email, ссылок/доменов, никнеймов и явных адресов перед любым вызовом внешнего провайдера.
- Для потенциальных контактных данных используется отказ с причиной `personal_contact_data`; такой текст не сохраняется и не передаётся OpenAI/OpenRouter.
- Убраны широкие стоп-подстроки, дававшие ложные срабатывания на обычных русских словах; локальная тематическая проверка оставлена в сценарии идей.
- Обновлены ответы API: они больше не обещают очередь ручной проверки, которой нет.
- Текст интерфейса для идей исправлен: FAM использует локальные правила, а не ИИ для этого сценария.
- Добавлены 5 локальных регрессионных тестов и GitHub Actions workflow для их запуска при изменениях модерации.

Развёртывание Supabase: `moderate v24 ACTIVE`, `submit-content v9 ACTIVE`, обе функции с `verify_jwt=true`.
Локальная проверка Node.js 22: 5 тестов пройдены. Удалённый результат GitHub Actions пока не подтверждён доступным просмотром запусков.
Публикация фронтенда на Netlify не проверялась; изменения фронтенда сохранены в GitHub.
