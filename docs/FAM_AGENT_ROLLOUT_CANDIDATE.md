## Нерешённые ограничения

Pending-review задача намеренно блокирует новые задания. Для завершения после решения владельца нужен отдельный проверяемый контракт GitHub → Supabase; пока только read-only reconciliation. Никаких автоматических release, fake owner_approved или completed. Испытания конкурентности покрывают три известных кооперативных входа на PostgreSQL, а не произвольные прямые DML. Повторный inference и полный live lifecycle не подтверждены этим PR. Независимый review и проверка полной локальной Supabase-схемы обязательны.
