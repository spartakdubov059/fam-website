# Журнал изменений FAM

Все даты указаны по дате внесения изменения. Статус публикации указывается только после фактической проверки.

## 2026-11-08

### Документация и рабочий процесс
- Добавлен документ с ролями команды, границами ответственности и очередностью внедрения.
- Зафиксированы приоритетные пробелы модерации: локальный детектор контактов объявлен, но не вызывается; для объявлений и сообщений нет подтверждённой общей очереди ручной проверки.
- Добавлены ссылки на официальную документацию OpenAI по Moderation API, лимитам и хранению данных.
- Добавлен стартовый синтетический набор русскоязычных регрессионных примеров для проверки безопасных текстов, контактов и возможных ложных срабатываний.

Статус: изменения документации сохранены в GitHub. Публикация сайта не требуется; изменения не меняют поведение приложения.


### Модерация и приватность
- Подключён локальный детектор телефонов, email, ссылок/доменов, никнеймов и явных адресов перед любым вызовом внешнего провайдера.
- Для потенциальных контактных данных используется отказ с причиной `personal_contact_data`; такой текст не сохраняется и не передаётся OpenAI/OpenRouter.
- Убраны широкие стоп-подстроки, дававшие ложные срабатывания на обычных русских словах; локальная тематическая проверка оставлена в сценарии идей.
- Обновлены ответы API: они больше не обещают очередь ручной проверки, которой нет.
- Текст интерфейса для идей исправлен: FAM использует локальные правила, а не ИИ для этого сценария.
- Добавлены 5 локальных регрессионных тестов и GitHub Actions workflow для их запуска при изменениях модерации.

Развёртывание Supabase: `moderate v24 ACTIVE`, `submit-content v9 ACTIVE`, обе функции с `verify_jwt=true`.
Локальная проверка Node.js 22: 5 тестов пройдены. GitHub Actions `Moderation regression tests` завершился `success`; проверка включает 5 Node.js тестов и синтаксис inline JavaScript. GitHub Pages build and deployment на том же commit также завершился `success`.
Публикация фронтенда на Netlify не проверялась; изменения фронтенда сохранены в GitHub.


### Фото и приватность изображений
- Перед загрузкой аватары повторно кодируются через canvas, ограничиваются 512 px и 2 МБ; фото объявлений — 1600 px и 5 МБ. Повторное кодирование убирает EXIF-метаданные исходного файла.
- Добавлены предупреждения: аватары и изображения объявлений доступны по публичным ссылкам; автоматической проверки содержимого изображений нет.
- Бакет `avatars` пока остаётся публичным, чтобы не сломать существующие ссылки до одновременного перехода фронтенда на подписанные URL и проверки опубликованных площадок. Перевод в private bucket оставлен блокером до широкого запуска.
- Содержимое фотографий не отправляется на внешний ИИ и не считается проверенным.


### Проверка существующих данных и RLS
- Агрегированно проверены 22 объявления, 2 идеи и 3 сообщения: основные шаблоны email, ссылок, телефоноподобных последовательностей, подписанных адресов и никнеймов совпадений не дали. Тексты и содержимое сообщений в отчёт не выводились; проверка не гарантирует обнаружение маскировки.
- Таблица `school_admin_requests` пуста, RLS включён, клиентские роли не имеют прав и политик нет. Таблица намеренно оставлена закрытой.
- Security Advisor: один INFO о закрытой таблице без политик и один WARN о выключенной защите скомпрометированных паролей. Health Advisor: ошибок нет.
- GitHub Actions workflow дополнен проверкой синтаксиса встроенного JavaScript в `index.html`. Результат удалённого запуска Actions пока не подтверждён.

- Сохранение прозрачности PNG/WebP при очистке метаданных проверено в коде; CI теперь также проверяет синтаксис встроенного JavaScript `index.html`.


### Доступ Ученического совета
- Исправлено отображение и рассмотрение заявок: RPC `request_id` приводится к ожидаемому фронтендом полю `id`.
- Email заявителей маскируется в серверном ответе Совету; UUID заявителя сокращается.
- Заявка принимает только одну из четырёх ролей, перечисленных в интерфейсе. Произвольный текст не сохраняется.
- Убран произвольный `review_note` из серверного запроса к RPC, так как пользовательский интерфейс не собирает заметки.
- Добавлены 4 регрессионных теста для приватности заявок и контракта интерфейса.
- Supabase: `school-admin-access v4 ACTIVE`, `verify_jwt=true`. Локальный Node.js 22: 4/4 новых теста пройдены.
