# Восстановление удаления школьных идей через Yandex ID — 21 ноября 2026

Исходная миграция `20261108001609_tighten_fam_ideas_and_event_registrations.sql` разрешает удалять свои идеи и идеи той же школы роли `school_admin`. RU API добавил поверх этого правила требование provider-attested `auth_time`. Обычная Yandex ID session в RU не несёт такого подтверждения, поэтому удаление чужой идеи администратором было недоступно через основной способ входа. Документация Yandex ID описывает доступные userinfo поля, но не документирует для них `auth_time`: [Yandex ID user information](https://www.yandex.com/dev/id/doc/en/user-information).

Снято только это дополнительное ограничение для удаления идей. Авторизация, same-school роль и активность аккаунта проверяются внутри YDB-транзакции; для чужой идеи API требует точную фразу `УДАЛИТЬ ИДЕЮ ШКОЛЫ`. Связанные изображения по-прежнему удаляются через lease cleanup, а действие администратора фиксируется в школьском аудите. Step-up требования для удаления аккаунта, управления блокировками и других операций не менялись.
