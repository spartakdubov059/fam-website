## Дополнение 13 ноября 2026, 10:22 UTC — разбор школьных SECURITY DEFINER RPC

- Повторно проверены определения четырёх RPC и их права выполнения. `anon` не имеет `EXECUTE`; `authenticated` имеет его намеренно. У всех функций `SECURITY DEFINER` и `SET search_path TO ''`, то есть имена объектов в теле квалифицированы схемами, а подмена через search path не видна.
