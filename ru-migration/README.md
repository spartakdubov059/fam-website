# FAM RU — изолированная миграция на Yandex Cloud

**Ветка миграции. Не сливать в main и не развёртывать на production.**

Цель — параллельно подготовить российскую копию FAM без остановки действующего сайта и без переноса реальных данных учеников до полной проверки.

## Проверенный этап 13 ноября 2026

- Создана эта отдельная ветка от `main`.
- В локальном комплекте FAM RU реализована защита от завершения проверки фото после истечения аренды: `locked_until > CurrentUtcTimestamp()` в SELECT и UPDATE.
- Локальные тесты: **215 из 215**, включая три новых теста на истечение lease и подтверждение транзакционного перехода.
- Патчи проверены: сначала `lease-expiry-guard.patch` применяется к версии с 212 тестами, затем `lease-transition-verification.patch` к версии с 214 тестами.
- **Реальная YDB, Object Storage, OAuth, модератор и расходы НЕ проверены.** Эти проверки нельзя заменять локальными тестами.

Полный локальный комплект пока хранится отдельно от этой ветки. Файлы в `ru-migration/patches/` фиксируют проверенные изменения исходников и тестов; сам по себе он не превращает текущий `main` в YDB-приложение.

## Требования к запуску

1. Завести пустое тестовое облако под управлением школы/взрослого и установить лимиты/уведомления о расходах.
2. Проверить YDB DDL на реальном тестовом экземпляре, транзакции, ограничения и роли.
3. Проверить изоляцию приватного Storage, модерацию, перевыпуск сессий и аккаунт-линкинг.
4. Перенести все функции и восемь расписаний, провести тесты параллельной обработки изображений.
5. Приобрести или активировать **никакие** платные ресурсы без отдельного разрешения владельца биллинга; production `main`, домен, Netlify и Supabase не изменять.

**Релиз заблокирован** до письменного подтверждения проверок безопасности школьников, интеграции YDB/S3 и полной сверки данных.
