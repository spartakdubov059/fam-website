# Проверка FAM RU — 20 ноября 2026

## Актуальное уточнение (20 ноября 2026)

- Кодовый commit [`65d2d44`](https://github.com/spartakdubov059/fam-website/commit/65d2d44f97a6199d7af61f5634fc04a46b690128) добавил read-only runtime checker `npm run check:timers` для пяти ожидаемых RU systemd units. Он выводит только allowlisted статусы `configured/enabled/active/nextScheduled`, не раскрывает timestamps/logs и ничего не включает. На Node 22.15.0 прошли `310/310` backend-тестов и SDK compatibility verifier. На этой macOS машине сама команда безопасно вернула `ok:false` и exit 1, поскольку `systemctl` отсутствует и RU таймеры не установлены; это ожидаемая диагностика. Синтетические unit-тесты покрывают healthy/degraded states и ошибки команд. [SDK/Sharp CI](https://github.com/spartakdubov059/fam-website/actions/runs/44676836958) и [одноразовая YDB CI](https://github.com/spartakdubov059/fam-website/actions/runs/44676837011) прошли.
