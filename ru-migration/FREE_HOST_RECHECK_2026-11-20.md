# Повторная проверка бесплатной российской среды — 20 ноября 2026

## Официальные условия

- [Yandex Cloud Free Tier](https://yandex.cloud/ru/docs/billing/concepts/serverless-free-tier): бесплатные объёмы применяются к billing account, суммируются по связанным организациям и облакам, после лимита услуги тарифицируются; неиспользованный бесплатный объём сбрасывается ежемесячно. Это квота, а не жёсткое ограничение максимального счёта.
- [Cloud.ru Free Tier для VM](https://cloud.ru/docs/virtual-machines/ug/topics/overview__free-tier): новые бесплатные VM доступны только аккаунтам, зарегистрированным не позднее 30 июня 2026 года; для доступа нужен положительный баланс; публичный IP и SNAT оплачиваются отдельно.
- [Cloud.ru Container Apps: тарификация](https://cloud.ru/docs/container-apps-evolution/ug/topics/pricing__container-services): ежемесячно бесплатны первые 25 vCPU×часов и 50 ГБ×часов RAM; расход выше квоты оплачивается по pay-as-you-go. Квота относится к сервису в организации, не гарантирует свободный объём для FAM.
- [Рег.облако Free Tier](https://reg.cloud/services/free-tier): предложение ограничено тремя месяцами и не подтверждает постоянное размещение FAM за 0 ₽.

## Решение для FAM RU

Ни одно из проверенных предложений не подтверждает одновременно общедоступный российский backend, auth/YDB/S3, достаточную длительность работы и гарантированный верхний предел списаний 0 ₽. До подтверждения из аккаунта владельца свободных квот, ограничений расходов и бесплатного сетевого доступа staging не создавать. Никакие ресурсы не запускались; тестирование продолжается на локальной disposable YDB и синтетических данных.

## Проверка локального подключения (20 ноября 2026)

В рабочем окружении FAM RU команда `yc` не установлена, файл профиля `~/.config/yandex-cloud/config.yaml` отсутствует, переменных окружения `YC_*`, `YANDEX*` и `AWS_*` нет. Проверка не обращалась к облачному API и не меняла ресурсы. Это подтверждает, что подключение Яндекс Cloud из текущей рабочей среды не настроено; это не доказывает отсутствие облачной учётной записи пользователя вне этого окружения.
