# CHANGELOG FAM

## 2026-11-08 — агенты безопасности, фото и обновление профиля

### ИИ и модерация
- Добавлен визуальный агент OpenAI GPT-5-mini для фото объявлений, школьных мероприятий и аватаров.
- Фото и аватары сначала загружаются в закрытые временные Storage-бакеты. В публичное хранилище они переносятся только после одобрения.
- Агент изображений не распознаёт людей и не устанавливает личность; сомнительные изображения остаются неопубликованными.
- Добавлен FAM User Safety Agent: сохраняет структурированные сигналы модерации без текстов переписок, имён, email и прямых ID участников.
- Сводные сигналы группируются по псевдонимному SHA-256 отпечатку; повторение повышает уровень внимания. Отчёты видит администратор своей школы в профиле.
- Для идей сохраняется отдельная проверка GPT-5-mini на спам, травлю и личные негативные призывы; конструктивная критика допускается.

### База и Storage
- Добавлена закрытая таблица `fam_safety_incidents` с RLS и запретом клиентского доступа.
- Добавлены private-бакеты `listing-images-pending` и `avatars-pending` с политиками доступа только к собственной папке.
- В таблице сигналов не хранятся исходные сообщения и прямые ID участников.

### Интерфейс
- Заявки на полномочия и заявки на мероприятия подняты в верхнюю часть профиля, выше собственных объявлений.
- Карточки объявлений стали компактнее и отображаются сеткой.
- В профиле администратора добавлена панель сводных отчётов безопасности.

- Оба временных фото-бакета подтверждены как private; проверены политики SELECT/INSERT/DELETE для папки владельца.
- RLS для `fam_safety_incidents` включён; клиентский доступ отозван.

### Ограничения проверки
- Сквозной пользовательский тест загрузки нового объявления, аватара и отображения отчёта ещё не выполнен.
- GitHub commit статусы для нового интерфейса вернули пустой список; live deploy GitHub Pages/Netlify в этом проходе не подтверждён.
- Существующие старые фото и аватары автоматически не проверяются повторно.
- Агент безопасности анализирует только сигналы модерации материалов внутри FAM, а не поведение за пределами платформы. Его выводы не являются доказательством и не заменяют ответственного взрослого.
- Отчёты показывают категории, источник, количество и даты, но не раскрывают личность участников и текст сообщений.
- GPT-5-mini выполняет дополнительный платный запрос для визуальной проверки каждого фото, прошедшего первичную модерацию; первичная Moderation проверка изображений выполняется отдельным вызовом.
